实现“亚马逊产品图生成”能力。用户上传 1也可能多张 张产品原图，并补充产品类目、核心卖点、尺寸/材质/包装信息后，系统自动生成一套可用于 Amazon Listing 的图片包。

调研结论：  
Amazon Listing 通常需要 8-9 张图，其中主图必须严格合规，辅图用于转化表达。
并行生成

1. 主图/白底 Hero 图  
用途：搜索结果和详情页首图。  
要求：纯白背景 RGB 255,255,255；产品占画面 85% 以上；无文字、水印、边框、道具、拼图或额外对象；建议输出 2000 x 2000 JPG。  
来源依据：Amazon Home/Garden/Pets Style Guide
备注：默认要做差异化

2. 卖点信息图/Feature Infographic  
用途：用标注、箭头、局部放大说明核心卖点。  
示例内容：材质、防水、续航、容量、食品级、适配场景等。  
注意：文字和图形只能放在辅图，不能放主图。

3. 使用场景图/Lifestyle  
用途：让买家理解产品在真实环境中的使用方式。  
示例：耳机在跑步场景、奶泡器在厨房、宠物食品和宠物同框。

4. 使用中/In-use 图  
用途：展示产品被人手持、佩戴、安装、操作的过程。  
适合：工具、电子产品、母婴、厨房用品、户外用品。

5. 细节/Close-up 图  
用途：展示材质、接口、纹理、按键、包装细节、工艺质量。

6. 尺寸/Scale 或 Dimension Callout 图  
用途：展示尺寸、容量、重量、和人体/常见物体的比例关系。  
适合：收纳、家具、宠物用品、电子配件、厨房用品。

7. 对比图/Comparison  
用途：和普通产品、旧款、竞品特性做结构化对比。  
注意：避免无法证实的绝对化宣传。

8. 包装/套装/品牌信任图  
用途：展示包装、配件清单、礼盒、质保、品牌故事或品质信号。

备注：不一定全部的图，要支持勾选

实际例子：  
GreenOnion 示例中，一个产品会生成 9 张图：Hero、Infographic、Benefits、Lifestyle、In-Use、Feature、Scale、Close-Up、Comparison。参考：GreenOnion Amazon Listing Images  
Seller Studio 示例中，一套 8 图包含：主图、生活方式图、尺寸标注、两张信息图和三张生活方式图。参考：Seller Studio

验收标准：  
- 输入 1 张产品图后，可生成至少 8 张 Listing 图。  
- 主图满足 Amazon 白底、无文字、无道具、产品占比 85%+ 的要求。  
- 辅图覆盖卖点、生活方式、使用中、细节、尺寸、对比、包装/品牌信任。  
- 输出统一为方图，建议 2000 x 2000，JPG/RGB。  
- 每张图需带类型标签，便于用户知道应上传到哪个 Listing 图片位。  
- 系统需保留每张图的生成提示词或结构化参数，便于二次编辑。
