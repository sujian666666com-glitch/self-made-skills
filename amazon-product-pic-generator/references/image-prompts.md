# Image Type Prompt Templates

Each template uses `{product}`, `{category}`, `{selling_points}` placeholders.

## Hero (主图)

```
Professional Amazon product hero shot, pure white background RGB(255,255,255), {product}, {category}, product fills 85%+ of frame, studio lighting, clean minimalist product photography, no text, no logo, no props, no border, high resolution
```

**Compliance**: White bg only, no text/logo/props, product ≥ 85%.

## Infographic (卖点信息图)

```
Amazon product infographic image, {product}, {category}, visually highlight features: {selling_points}, clean modern design with callout arrows and labels, light gradient background, professional e-commerce graphic design, 2000x2000
```

## Lifestyle (使用场景图)

```
Amazon lifestyle product photo, {product} in a realistic {category} usage scene, natural lighting, warm atmosphere, product clearly visible, aspirational but authentic, high-quality photography
```

## In-Use (使用中)

```
Amazon product in-use photo, {product} being held and operated by a person's hands, {category}, showing real interaction with the product, natural indoor lighting, professional product photography
```

## Close-Up (细节图)

```
Amazon product close-up detail shot, {product}, extreme detail showing material texture, craftsmanship, buttons, connectors, macro photography style, shallow depth of field, studio lighting, {category}
```

## Dimension (尺寸标注)

```
Amazon product dimension/size reference image, {product}, showing proportions with measurement annotations or human-scale comparison, clean technical illustration style, light background, {category}
```

## Comparison (对比图)

```
Amazon product comparison image, {product} alongside a generic/ordinary alternative, structured side-by-side comparison layout, highlight advantages: {selling_points}, clean modern design, professional e-commerce graphic
```

**Note**: Avoid unverified absolute claims.

## Packaging (包装/品牌信任)

```
Amazon product packaging and accessories display, {product} with all included items neatly arranged, premium unboxing feel, clean flat-lay or angled composition, light neutral background, {category}
```
